# 高精度控制测量 · 卫星可见性规划后端

为外业高精度控制测量批量挑选"卫星几何条件好"的观测时段的后端服务。
导入卫星历书与点位遮挡轮廓，批量计算每个点位在给定日期范围内的
GDOP/PDOP/HDOP/VDOP/TDOP 变化，给出所有满足阈值与最短时长的连续可用时段；
历书或点位更新后自动重新规划并输出差异。

* Python 3.12 + Flask + NumPy（轨道传播与 DOP 全部自行实现，不使用任何
  卫星导航/天文第三方库）
* MongoDB 7 持久化版本与结果
* pytest 测试（用 mongomock 做持久化替身，无需起 Mongo 即可跑全部测试）

## 快速开始

```bash
# API: http://localhost:8080
```

## 可见性与 DOP

* 某卫星在某时刻可见，当且仅当其高度角 **严格高于** 该方位的遮挡高度角
  （`el > mask(az)`）；遮挡轮廓是按方位角给出的一组高度角控制点，方位角
  落在控制点之间时做环形线性插值，未覆盖方向用统一截止高度角兜底，
  截止角是任何方向上的最低门限。
* 可见卫星 ≥ 4 时构造几何矩阵（每颗可见星一行 `[-e,-n,-u,1]`），
  `Q=(GᵀG)⁻¹`，则
  `GDOP²=tr(Q)=PDOP²+TDOP²`、`PDOP²=HDOP²+VDOP²`；
  少于 4 颗或几何退化（矩阵不可逆）时该时刻不可用。
* 核对几何：天顶 1 颗 + 高度角 30°、方位角 0°/120°/240° 3 颗，
  GDOP=√85/3≈**3.073**（HDOP=4/3、VDOP=4/√3、TDOP=√(7/3)、PDOP=8/3）。

## 时段搜索策略与漏检上界

见 `app/search.py` 顶部文档。要点：

1. **粗扫描**：以 `scan_step_s`（默认 60 s）为间隔在半开整数秒网格上
   批量评估每个时刻的可用状态（≥4 星且 GDOP≤阈值）。
2. **边界细化**：相邻网格点状态不同的"跨越单元"，把单元内部所有整数秒
   一次性批量评估，逐秒收集状态翻转事件。这对 **GDOP 连续穿越阈值** 与
   **卫星在遮挡轮廓处升起/落下造成的跳变** 同样适用（不假设连续或单峰）。
3. 由翻转事件拼成精确到 1 秒的半开区间，再按最短时长过滤。
4. 每个可用时段内，先在已采样点找 GDOP 最小处，再在其两侧 ±2 个步长内
   逐秒局部加密，报告区间内 GDOP 最小值与其出现时刻（整秒）。

**不漏检结论**：任何持续时长 **≥ `scan_step_s`** 的连续可用时段必定被
发现（它必然覆盖至少一个网格点，从而让相邻单元成为跨越单元并被逐秒
细化）。因此被漏掉的尖峰若存在，其持续时长 **严格小于 `scan_step_s`**，
即**漏检最短时长上界 = 扫描步长**（默认 60 秒）。不可用的短时缺口同理。
边界时刻由逐秒加密给出，在整秒网格意义下误差为 0。

测试 `tests/test_search.py` 用人造尖峰验证：

* 120 s 的好尖峰跨在网格之间 → 被找到，边界精确到秒；
* 15 s（< 60 s）且完全落在单个单元内部 → 允许漏检（正是上界结论）；
* 覆盖到网格点的 10 s 尖峰 → 仍被捕获。

> 说明：同态单元（两端状态相同）内部不细分，这是"快"的来源；需要更短的
> 保证时调小 `scan_step_s`（规划参数可按任务覆盖），代价是评估次数线性增加。

## 版本、自动重规划与差异

* 历书每次导入生成新版本（旧版本保留）；点位（含遮挡轮廓）按 `point_id`
  各自维护版本，历史版本保留。
* 每份规划结果**绑定**历书版本、逐点位版本和参数快照。
* 导入新历书：对所有**日期范围终点仍在未来**的规划自动发起重规划；
  修改某点位：对引用它且仍在未来的规划重算。
* **作业取代**：同一计划上尚未完成的作业会被新作业取消让位；连续两次
  历书更新时，旧的重规划作业被取消，最终每份规划只保留基于最新历书的
  当前结果和**一份历史**。
* **取消语义**：作业在每个点位与每个跨越单元检查取消信号；取消后绝不
  写入部分结果。结果落库时再做一次历书版本检查（旧作业结果不会覆盖
  更新历书版本的结果）。
* 差异（`app/diff.py`）逐点贪心配对新旧窗口，归类为
  **消失 / 缩短 / 平移 / 新增**；窗口不重叠但间隔不超过 `match_gap_s`
  （默认 120 s）仍视为同一条，间隔更大则分别计为消失与新增。

## 共享计算

`SharedSkyCache` 以 `(历书版本, 点位版本, 卫星, 整数秒)` 为键缓存单星
方位角/高度角。同一点位被多份规划引用时：

* 同一时刻只做一次轨道计算（带"在途键合并"：两个线程同时请求同一缺失键，
  只有一个执行计算，另一个等待复用）；
* 结果只依赖历书根数与点位版本，因此共享结果与单独计算**逐位一致**
  （有端到端测试：两份共享规划的窗口 == 独立缓存单份规划的窗口）。

## HTTP 接口

| 方法 路径 | 说明 |
|-----------|------|
| `POST /api/almanacs` | 导入历书（返回新版本号，自动触发未来规划重算） |
| `GET  /api/almanacs` | 历书版本列表 |
| `GET  /api/almanacs/<ver>` | 某版本历书详情 |
| `PUT  /api/points` | 新增/更新点位（版本自增，触发相关重算） |
| `GET  /api/points` / `/<pid>` / `/<pid>/versions/<v>` | 点位查询 |
| `POST /api/sky/observe` | 单时刻可见卫星与 DOP（可选 `gdop_threshold`，支持内联点位） |
| `POST /api/plans` | 提交规划（异步，202 返回 `plan_id`/`job_id`） |
| `GET  /api/jobs/<job_id>` | 查询作业进度 |
| `POST /api/jobs/<job_id>/wait?timeout=` | 等待作业结束 |
| `POST /api/jobs/<job_id>/cancel` | 取消作业（不写部分结果） |
| `GET  /api/plans` / `/<plan_id>` | 规划列表/定义 |
| `GET  /api/plans/<id>/result` | 当前结果（含版本绑定） |
| `GET  /api/plans/<id>/history` | 历史结果（一份） |
| `POST /api/plans/<id>/diff` | 与历史/另一规划做结果差异对比 |

### 历书格式

角度可给弧度（`inc`）或度（`inc_deg`）。半长轴给 `sqrt_a`（√m）或
`semi_major_axis`（m）。

```json
{
  "source": "2026-W40",
  "satellites": [
    {"sat_id": "G01", "semi_major_axis": 26559800.0, "ecc": 0.005,
     "inc_deg": 55.0, "raan0_deg": 0.0, "raan_rate": -8e-10,
     "argp_deg": 30.0, "ma_deg": 0.0, "toe": "2026-01-01T00:00:00Z"}
  ]
}
```

### 点位与遮挡轮廓

```json
{
  "point_id": "BJ01", "lon_deg": 116.391, "lat_deg": 39.907,
  "height_m": 50.0,
  "mask": {"cutoff_deg": 7.0,
           "points": [[0, 20], [90, 15], [180, 25], [270, 10]]}}
```

`points` 为 `[方位角度, 遮挡高度角度]` 控制点；方位角必须在 [0,360]，
不允许重复（0 与 360 视为重复）。

### 规划参数

```json
{
  "point_ids": ["BJ01"],
  "date_start": "2026-11-05T00:00:00Z",
  "date_end":   "2026-11-07T00:00:00Z",
  "gdop_threshold": 6.0,
  "min_duration_s": 300,
  "scan_step_s": 60
}
```

## 拒收规则（HTTP 400）

* 偏心率不在 [0,1)；
* 半长轴不为正；
* 纬度越界（[-90,90]）；
* 遮挡轮廓方位角不在 [0,360] 或有重复；
* GDOP 阈值不为正；
* 最短时长为负；
* 日期范围结束早于开始。

## 测试

```bash
pytest                 # 全部
pytest -k spike        # 短时尖峰/漏检
pytest -k supersede    # 连续历书更新取代
```

覆盖（对应需求清单）：

* 几何核对例子（GDOP≈3.073）与手算精确值；
* GDOP²=PDOP²+TDOP²、PDOP²=HDOP²+VDOP²；
* 同一时刻加星 GDOP 不变大；
* 遮挡轮廓整体抬高，可用时段只缩短/不变（集合包含 + 总时长单调）；
* 人造短时尖峰被发现 / 亚步长尖峰漏检符合上界；
* 时段边界精确到 1 秒（连续穿越与升/落跳变两类）；
* 历书更新后的差异（消失/缩短/平移/新增）；
* 连续两次历书更新的作业取代与"只留一份历史"；
* 作业取消后不写部分结果；
* 共享缓存去重且与单独计算逐位一致；
* 所有拒收规则；
* 服务重启后未完成作业标记为 interrupted；只对未来规划自动重算；
* 批量与单点评估严格一致的形状回归测试。
